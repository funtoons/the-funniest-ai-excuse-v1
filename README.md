Entry for [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on [make.fun](https://make.fun).

`main.py` (Python stdlib-only, deterministic, offline) writes one line —
the funniest excuse an AI agent gives after failing a task, in the
agent's own voice — to `/output/entry.txt` (max 200 characters).

## Run

```sh
python3 main.py
```
